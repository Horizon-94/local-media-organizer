## 维护入口与回退

维护工具只面向已有匹配的本地1.2.6安装及运行环境，**不是通用升级器**。
它只热替换前端，不会补装缺失的旧版后端；不要对1.2.3/1.2.4/未知基础版本执行。
`v126_ui_hotfix7.py`是共用实现，维护本版必须从`v126_ui_hotfix9.py`进入，不能直接执行旧编号入口。
需要正常退出App、保留备份，并先验证现有基础环境。源码记录本身不执行安装。

```sh
mkdir -p logs
python3 tools/v126_ui_hotfix9.py prepare
python3 tools/v126_ui_hotfix9.py install
```

工具只备份被替换的小文件，保存安装前后哈希，签名失败回滚；不会复制整个App。
已有同名准备/安装记录时拒绝覆盖。回退只允许应用状态仍与本次安装清单一致：

```sh
python3 tools/v126_ui_hotfix9.py rollback
```

回退资料位于执行目录的`test-output/v126-hotfix-ui9-20260829/`，日志在`logs/`。
它们和个人工程不进入Git。已安装本版的使用者无需再次执行。
