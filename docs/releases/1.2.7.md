# 本地数据库 1.2.7：通用跨素材库搜索与前台优化

日期：2026-08-31。版本标签：`v1.2.7`。

## 版本定位

1.2.7 在1.2.6维护源码基础上继续收口搜索和选片交互，不重做素材扫描、抽帧、视觉分析、人物、OCR、ASR或数据库结构。

所有新增逻辑均为通用实现：不依赖具体纪录片、文稿、人物、题材、素材库名称或维护者电脑路径。真实项目仅用于本地只读验收，不是规则来源，也不进入公开仓库。

## 谁适合使用

- 需要整理大量本地图片和视频，并希望原始素材保持只读的个人创作者。
- 需要在多个项目素材库之间统一查询，但仍保留每个素材库独立收藏、备注和工程状态的用户。
- 使用 DaVinci Resolve、Final Cut Pro 等剪辑软件，希望先完成逐句人工选片和粗剪清单的人。
- 纪录片、人物、旅行、城市、活动、产品、农业、工业、生活记录和普通口播+B-roll项目均可使用；1.2.7没有按某个项目名称或题材写死规则。

## 从安装到使用

### 1. 安装应用

1. 下载 Release 中的 `本地数据库 1.2.7-1.2.7.dmg`。
2. 核对本页 SHA-256，把 App 拖入“应用程序”。
3. 当前公开包为 Apple Silicon arm64，不支持 Intel Mac；使用 ad-hoc签名、尚未经过Apple公证，首次打开可能需要在macOS安全设置中确认。

### 2. 准备本地模型

DMG包含应用和Python运行环境，不包含第三方模型，也不会自动联网下载模型。按仓库中的模型安装说明自行下载后，进入“设置 → 本地模型位置”，选择包含各模型子目录的总目录并点击“检查并保存”。11项均显示“已找到”后退出并重新打开应用。

### 3. 建立素材库

“素材文件夹”选择原始图片和视频目录；“索引保存位置”选择数据库、预览、抽帧和报告的保存目录。素材目录始终只读，派生数据写入索引目录。任务失败会保留断点，不会因重试而改写原片。

### 4. 搜索素材

“当前素材库”用于一个项目内查询；“全部素材库”逐库只读查询所有已登记数据库，再统一排序。普通画面搜索融合视觉向量、画面描述、物体标签和OCR；人声转写必须单独选择音频搜索。相邻重复抽帧会按原视频聚合，需要时可展开该视频全部画面。

### 5. 文稿选片

导入PDF、TXT或直接输入文稿，可另外添加逐句Excel作为项目指导。系统按真实文稿分句并返回候选，用户可选择主选、备选、拒绝、保留人物口播或素材缺口。候选解释会区分“为什么搜索到”和“为什么适合剪”，但不会代替用户最终决定。

### 6. 导出与精剪

主选作为第一视频层，备选作为第二层参考；人工播放原片后可调整并锁定入出点。正式结果为FCPXML粗剪时间线和剪辑清单JSON。DaVinci Resolve可导入兼容FCPXML并重新连接原始素材，随后继续精剪、声音、调色和字幕工作。

## 搜索

- 搜索范围可选择“当前素材库”或“全部素材库”。
- 全部素材库模式逐库只读查询已登记数据库，再统一排序；不可搜索的库会被跳过并返回诊断。
- 同一原文件被多个素材库收录时，只保留综合得分最高的结果。
- 每条结果保存所属素材库身份，后续播放、Finder、收藏、备注和视频画面展开均使用对应数据库。
- 文稿选片的人工补选固定使用当前工程素材库，不允许跨库结果误写选片时间线。
- 普通视觉搜索按原视频合并相关抽帧；音频转写筛选继续保留同一视频中的不同对白时间点。
- 搜索整理阶段支持增量显示；最终结果仍是唯一权威排序。
- 最近查询可点击复用本地缓存并在后台刷新；缓存只保存结果元数据和既有预览路径。
- “全部画面”只包含图片与视频视觉证据；人声转写只进入音频筛选。

## 前台与工程维护

- 人物分组改为按需读取，普通搜索不再自动构建人物选择器。
- 搜索状态刷新频率降低，较大JSON在后台解码。
- 长选片工程的连续修改采用短时合并保存；正常退出仍立即提交最新状态。
- 搜索框扩大可点击区域，结果文字可以选择和复制。
- 历史任务保留其真实原始阶段，同时单独展示后补音频、修复和重建记录；不伪造旧任务当时不存在的阶段。

## 数据安全

- 原始素材只读；本次没有上传、移动、重命名或删除任何素材。
- 素材数据库不进入Git；跨库搜索以只读方式打开数据库。
- 模型、Python运行环境、搜索缓存、收藏、选片工程、PDF、Excel、日志和真实测试数据均不进入Git。
- 不修改数据库Schema，不重新扫描素材，不重新构建索引。
