# 本地数据库 1.2.3

1.2.3 是以 1.2.2 精简发行结构为基础的 Apple Silicon 完整版。它保留图片、视频、OCR、人物、音频转写、向量搜索、历史索引切换和断点恢复，只增加已经定向验证的人物候选复核能力。

## 新增功能

- 人物页面新增“查看侧脸/背影候选”。
- 候选生成复用现有数据：已确认人脸锚点、YOLOE 人体框、来源视频与相邻时间关系。
- 候选默认按来源和时间去重，并明确标记为“待人工确认”。
- 不需要新增模型或额外下载权重。

## 安全边界

- 不自动把背影、侧脸或远景认定为某个人。
- 不自动跨视频合并身份；换衣、跨场景身份仍需人工确认。
- 不重新运行人脸、YOLOE 或视频抽帧模型。
- 不写原始素材，不覆盖既有人脸 embedding、人物组和中央数据库。

## 延续能力

- 多个历史索引库可以切换，并从当前选中的数据库执行真实搜索。
- 人物名称、标签、收藏、备注、人工合并与拆分保存在各索引本地覆盖层。
- 图片、视频、OCR、视觉描述、标签、向量和音频转写证据继续参与离线搜索。
- 视频结果可从命中时间播放，并支持在 Finder 中定位源文件。
- 长任务保留逐项提交、断点恢复、worker 状态和错误详情。

## 发行包

- 版本：`1.2.3`（build `123`）。
- 架构：Apple Silicon `arm64`；不提供 Intel、Rosetta 或 Universal Binary。
- 完整 App 包含当前运行脚本与六套便携 Python 运行环境。
- 发行白名单排除历史实验脚本、原始素材、真实索引、日志、访问令牌和维护者本机配置。
- 不包含模型；模型仍由用户从上游下载并在设置中选择本地目录。
- 可选 DeepFilterNet 可执行文件也不进入 Git；发行构建通过 `MEDIA_ARCHIVE_DEEP_FILTER_EXECUTABLE` 显式提供。
- 签名为 ad-hoc local，尚未使用 Apple Developer ID 公证。
