# 本地数据库 1.2.0

1.2.0 以已经完成真实项目验收的 1.1.9 为基础，将安装后验证的音频热修复正式纳入源码和发行包，不重写既有图片、视频、人物、搜索、断点与中央数据库能力。

## 新增功能

- 视频人声搜索：本地 VAD、可选降噪、Whisper 转写、时间戳、文本向量与只读搜索融合。
- 音频任务支持 1～3 路并发，并按视频提交数据库和断点。
- 搜索素材类型新增“音频（人声转写）”。它返回带有人声证据的视频，不虚构独立音频素材。
- 结果显示转写原文、音频命中时间段、直接命中或语义命中原因。
- 中间 WAV 在成功提交后删除；长期保留转写、时间范围、来源关系与向量。

## 修复

- 修复低相关音频文本误进入结果后触发空分数组崩溃的问题。
- 确保回车键可以开始搜索。
- 延续历史素材库切换，并从所选数据库执行真正的图片、视频、文字与音频证据搜索。
- 资源卡明确区分进程树 CPU、RSS 与系统 Swap，避免把系统级和任务级数字混为一谈。

## 发行边界

- 仅支持 Apple Silicon arm64（M1 及后续 M 系列）。
- 完整 App 包含应用脚本与六套 Python 运行环境。
- 不包含模型、原始素材、用户数据库、历史任务、访问令牌或维护者本机路径。
- 模型由用户从上游下载，放到自选模型根目录后在设置中选择。
- GPL-3.0-only；官方源码：<https://github.com/Horizon-94/local-media-organizer>。
