# V0.1 Freeze

V0.1 已冻结。

冻结范围：

- 扫描目录
- 记录路径、大小、扩展名、mtime
- 区分 video、image、raw_image、audio、sidecar、subtitle、metadata、unsupported、unknown
- 对普通视频执行容器级 / stream 级 light metadata probe
- 记录 metadata_status、risk_flags、next_stage_hint
- 原始素材只读
- 输出 manifest
- 输出 FFmpeg / FFprobe audit
- 输出 scan policy report
- 输出 per-video timing csv
- 输出 V0.1 stage state
- 重复运行稳定

V0.1 Light Scan 已固化为完整 run 入口第一阶段。

正式入口：

```bash
python3 -m apps.media_archive.app v01-scan --source <source_dir> --workspace <workspace_dir> --fresh
python3 -m apps.media_archive.app run --source <source_dir> --workspace <workspace_dir> --fresh
```

`run` 当前只执行 V0.1 并停止，后续阶段记录为 `not_run`，不得伪装完整流程成功。

V0.1 light metadata probe 只允许读取：

- format: duration, size, bit_rate, format_name
- stream: index, codec_type, codec_name, width, height, r_frame_rate, avg_frame_rate, duration, pix_fmt

V0.1 默认禁止：

- ordinary_video_integrity_check
- ordinary_video_sample_decode
- full_integrity_check
- deep_integrity_check
- `ffmpeg -f null -`
- `ffprobe -show_frames`
- `ffprobe -show_packets`
- `ffprobe -count_frames`
- `ffprobe -count_packets`
- scene detection
- showinfo
- preview / JPG generation
- audio proxy
- AI model calls
- search index
