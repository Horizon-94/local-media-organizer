# 素材大整理通用抽帧与高价值密度规则 V1

## 适用范围

本规则适用于任意图片和视频素材库，不使用项目固定数量，也不修改已冻结的 V25 文件。

## 视频抽帧

- 用户可选 1、2、3、4、5 秒抽取一帧。
- 不提供 10 秒选项。
- 每个新任务把所选间隔写入任务配置快照。
- 抽帧合同、派生帧标识、manifest 和数据库记录使用该任务的真实间隔。
- 已有任务断点续跑继续使用创建任务时的间隔，不被后来修改的默认设置覆盖。

## 视频高价值密度

- 用户可选兼容当前规则、15%、20% 或 30%。
- 15%、20%、30% 是对每个视频当前合格派生帧数量计算，不是固定输出张数。
- 每个非空视频的目标数为 `ceil(合格派生帧数 × 目标比例)`。
- 视频时间轴按目标数量分箱，每个时间箱选择一张证据分最高的帧；没有高信号时仍保留确定性的代表帧。
- 黑帧、坏签名、屏幕录制和非 canonical 重复帧不进入比例基数。
- 输出 summary 必须同时记录合格数、期望选择数、实际选择数和逐视频计算结果；数量不一致时技术状态为 FAIL。

## 全部图片进入高价值分析

- 选择“所有普通图片都进入画面描述”后，候选数量完全由当前数据库中的 canonical 图片计算。
- 已有成功结果、已在冻结候选中的图片和已进入补充队列的图片不重复运行。
- 延时摄影组继续使用特殊素材入口，不把同组每张图片重复当作普通图片候选。
- 新建完整任务和修复缺失内容都必须使用任务快照中的图片范围设置。

## 通用性与兼容性

- 公式可以冻结，任何项目的输出数量都不得写死。
- 冻结 V25 只作为兼容模式和既有数据库合同保留。
- 新通用适配器不修改原始素材，不写模型目录，不下载或运行模型。
