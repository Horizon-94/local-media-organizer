# 素材大整理：本机运行时合同 V1

状态：冻结候选（随 1.0.25 QA 应用验证）

## 目的

软件不再分别猜测 Python、模型、脚本和配置的位置。所有固定位置统一记录在：

`configs/media_archive_app_runtime_contract_v1.json`

新任务启动前必须只读检查这份合同。任一固定组件缺失时，任务不得开始，并明确显示缺失项。

## 固定内容

- 6 个 Python 运行环境：基础视觉、YOLOE、Qwen-VL、OCR、文本向量等。
- 7 组本地模型资产：YOLOE、MobileCLIP、OpenCLIP、Qwen-VL、OCR 检测、OCR 识别、文本向量。
- 18 个正式阶段或搜索脚本。
- 9 个正式规则或运行配置。
- 4 个中心数据库 migration。

这些位置属于本机安装合同，不由普通任务页面修改。虚拟环境 Python 路径必须保留原始入口，禁止解析成 Homebrew 基础 Python。

## 用户可变内容

- 本次要整理的素材文件夹。
- 本次索引库和派生文件保存位置。
- 任务名称。
- 已开放并通过合同校验的处理参数，例如并行数与冻结规则允许的抽帧设置。

素材数量、视频数量、图片数量和候选数量一律按所选文件夹实时计算，不写死任何测试项目数字。

## 安全边界

- 原始素材只读。
- 模型目录只读。
- 禁止联网和下载。
- 所有数据库、派生文件、日志和报告只写入所选素材库 workspace。
- 当前正式调度仍是阶段串行；“数据库流水线异步”尚未实现，界面必须标为不可用，不得伪装成已开放。

## 启动判定

只有运行时合同的 `ready=true`，软件才允许启动完整整理。合同自检只检查文件和目录是否存在，不加载模型，也不读取原始视频内容。
