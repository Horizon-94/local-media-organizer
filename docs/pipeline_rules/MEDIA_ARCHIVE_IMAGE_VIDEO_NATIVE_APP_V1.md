# AI 本地素材库：图片与视频原生应用 V1

状态：`UI_INTEGRATED / FROZEN_BACKEND_CONNECTED / PIPELINE_LAUNCHER_PENDING`

## 1. 界面边界

- 当前界面只显示图片和视频。
- 音频、文本接口保留，但不在导航、筛选、统计和结果列表中显示。
- 所有数量按当前中心数据库动态读取，不以任何测试项目数量作为完成门槛。
- 原始素材只读；派生缩略图、任务配置和搜索临时结果只写应用输出目录。
- 应用使用 Python 原生窗口，不启动本地 Web 服务器。

## 2. 已连接能力

- 中心 SQLite 素材、视觉单元、阶段 run、重复组和延时摄影组只读查询；
- Stop03-5E V2 全视觉搜索；
- 派生帧缩略图；
- 视频命中点和 5/10 秒预览区间；
- Finder 与系统播放器入口；
- 数据库完整性、外键和本地运行环境检查。

搜索原文和查询向量不写入中心数据库，也不写入应用状态文件。搜索子进程强制离线环境。

## 3. 尚未冒充完成的能力

当前冻结清单没有“从任意新文件夹自动执行全部阶段”的统一总编排器。新建任务页仅检查路径并保存
通用任务配置，状态为 `AWAITING_FROZEN_PIPELINE_ORCHESTRATOR`。在总编排合同冻结前，应用不会把
多个历史脚本临时串联成正式全量任务。

## 4. 通用性

应用代码不包含固定素材数、固定候选数或固定 run ID。项目根、中心数据库、输出目录和两套本地 Python
运行时均由应用安装配置提供。换素材库时按实际数据库和文件夹动态计算。

## 5. 桌面安装

构建同时生成 `.pkg` 和 `.dmg`。安装后应用位于 `/Applications/AI本地素材库.app`，用户可从
“应用程序”、启动台或 Dock 打开，不需要启动终端或浏览器。本地构建为 ad-hoc 签名；公开跨设备分发
仍需要 Apple Developer ID 签名和公证。
