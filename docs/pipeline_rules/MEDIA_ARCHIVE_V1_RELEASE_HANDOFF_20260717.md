# AI 本地素材库 V1 发布交接

版本：`1.0.1-image-video`

## 用户可直接使用

- 安装后从“应用程序”、启动台或 Dock 打开，不需要终端和浏览器；
- 只显示图片和视频；
- 搜索覆盖中心数据库中的全部视觉单元；
- 每条结果显示文件名、所属文件夹、完整相对路径、视频命中点和 5/10 秒区间；
- 可以直接在 Finder 中定位文件；
- 视频通过 QuickTime 打开并跳到命中区间起点；
- 运行页按数据库实际总数显示完成、剩余和动态预计时间；
- 原始素材只读。

## 当前发布边界

当前已经处理完成的中心素材库可以完整搜索。任意新文件夹的全链路总编排器尚未冻结，因此“新建任务”
只保存通过安全检查的通用任务配置，不会冒充已经启动模型。该缺口不影响当前数据库的查看和搜索，后续
版本只需把冻结总编排器接入已有任务接口。

音频和独立文本接口仍保留在后台，但 V1 导航、筛选、结果和统计不显示它们。

## 发布物

- `AI本地素材库-1.0.1.pkg`：双击系统安装；
- `AI本地素材库-1.0.1.dmg`：拖入“应用程序”；
- `AI本地素材库-V1.0.1-冻结证据-final.zip`：冻结规则、配置、脚本、迁移和测试证据。

本地构建采用 ad-hoc 签名。若未来公开分发给其他 Mac，需要另行使用 Apple Developer ID 签名和公证；
这属于发布签名工作，不改变本地处理和搜索逻辑。
