# 素材库位置与特殊素材入口重建规则 V1

## 适用情况

用户只调整了已有素材的文件夹位置、合并或拆分延时摄影目录，希望保留已完成的识别结果并更新素材入口。

## 通用规则

1. 原始素材始终只读，不移动、不重命名、不删除、不改写。
2. 当前扫描结果是本次素材位置快照，不使用固定文件数或固定分组数。
3. 相同内容移动后保留 `source_content_id`，只更新当前绝对路径和相对路径。
4. 本次扫描没有看到的旧记录只标记为离线或缺失，不删除其历史识别证据。
5. Finder 标签、文件清单、sidecar 关系和文件夹统计以本次完整扫描快照替换旧快照。
6. 延时摄影按当前目录和冻结检测公式重新分组；`step02_image_timelapse_keyframes` 用本次 Step02 清单整表替换，不累计旧分组。
7. 此模式不运行 YOLOE、OpenCLIP、Qwen-VL、OCR 或文本向量模型。
8. 如果发现真正新增或内容发生变化的素材，本模式只更新位置与分组，不伪造其模型结果；新增内容应进入后续正式增量整理。

## 状态含义

- 技术 PASS：扫描、图片预览复用/生成和分组表替换均成功，数据库完整性正常。
- 策略 PASS：旧分组已被当前分组替换，所有数量均由当前素材动态计算。
- 策略 REVIEW：发现新增或内容变化素材，需要正式增量整理。
- 策略 FAIL：当前素材目录不可读、数据库不可写或分组清单无法生成。
