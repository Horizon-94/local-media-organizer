# 可验证版本路线

维护者：Horizon-94
官方仓库：<https://github.com/Horizon-94/local-media-organizer>

本页只整理当前仓库中仍能由冻结文档、测试或源码验证的路线。没有可靠证据的内部中间编号不会伪造成 Git 提交或正式 Release。

| 阶段 | 可验证结果 |
|---|---|
| V0.1 | 原始素材只读扫描、基础清单、可恢复阶段状态 |
| V0.2 | 固化 A9T-v3 图片预览；固化 R2J-FIX-C4 视频抽帧；C6 不作为默认方案 |
| V0.4 | 来源关系、去重、派生预览和中央 SQLite 数据库收口 |
| V0.5 | YOLOE、OpenCLIP、Qwen-VL、OCR、文本向量和统一证据链路 |
| V0.5 Stop03-2 | 候选规则经过多轮设计复核，最后冻结到 V25 |
| V0.5 Stop03-5E | 从文本查询入口演进到覆盖全部视觉向量的混合搜索 V2 |
| 1.0.x | 图片/视频原生界面、运行合同、模型合同与构建入口 |
| 1.1.3 | 完整本地数据库只读搜索和运行状态展示 |
| 1.1.4 | 搜索阶段进度、检查数量、流式候选结果、暖缓存和取消修复 |
| 1.1.4 GPL 发布整理 | 当前代码改为 GPL-3.0-only；增加通用模型布局、源码构建、发行包隐私审计和公开历史 |
| 1.1.5 本地验证候选 | 每视频原子断点、真实运行指标、AppleDouble 排除、人物本地管理、重复素材核对与搜索缓存；2.2 TB 从零验收待完成，未正式发布 |

详细变化见仓库根目录的 `CHANGELOG.md` 和
[`1.1.4_TO_1.1.5.md`](1.1.4_TO_1.1.5.md)。历史文档不是性能承诺；
正式 Release 以 GitHub 的标签、提交号和附件校验值为准。
